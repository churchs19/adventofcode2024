# Advent of Code 2024

[https://adventofcode.com/2024](https://adventofcode.com/2024)

## Prerequisites

* [.NET 8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

## Building

```sh
dotnet restore
dotnet build
```

## Testing

```sh
dotnet test
```

## Running

```sh
cd ./aoc2024
dotnet run
```
